RULES:

1. Do not invent a new Sparovia color palette.
2. Do not replace the orange primary CTA with another color.
3. Do not use WhatsApp green as a general Sparovia brand color.
4. Do not introduce arbitrary gradients.
5. Do not randomly change the brand blue or purple.
6. Maintain the existing Sparovia visual identity across Admin UI, authentication, onboarding, content management, image management, AI UI and lead management.
7. Use semantic colors only for their semantic purpose.
8. Reuse centralized design tokens/CSS variables/theme tokens instead of hardcoding colors throughout components.
9. Existing Sparovia Landing Page visual identity must remain unchanged.
10. New Admin UI should feel like the same Sparovia product family, not a separate application.
11. Preserve the premium, clean, modern visual language shown in the existing Sparovia website.
12. Any new component must consume the centralized Sparovia design tokens.
13. Before introducing a new color, first determine whether an existing locked token can satisfy the requirement. Prefer the existing token.
14. Do not alter the locked palette without explicit product-owner approval.

The Sparovia color system is a product-level design constraint, not a suggestion.
